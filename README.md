# SGEN — Sound Generator

Модульный генератор звука, который целиком работает в браузере: Web Audio API,
AudioWorklet и Canvas. Сервер не участвует в обработке звука — только отдаёт
статические файлы.

**Живая версия:** https://sgen.ddns.net/sgen/

## Возможности

- до 16 независимых генераторов одновременно;
- аддитивный синтез: 16 гармоник, амплитуда −1…1 (знак задаёт фазу);
- пресеты: синус, пила, квадрат, треугольник;
- белый, розовый и коричневый шум;
- FM (глубина и отношение) и AM (частота и глубина);
- частота, амплитуда, фаза, панорама;
- живой осциллограф с триггером по нулю;
- «замершая» волна — снимок сигнала по кнопке;
- спектроанализатор 20 Гц — 20 кГц с удержанием пиков;
- сохранение патча в `localStorage` и шаринг ссылкой `#p=...`;
- плавные огибающие при пуске и остановке.

## Запуск

Ни сборки, ни зависимостей нет — это статические файлы.

```bash
python -m http.server 8000
```

Открыть http://localhost:8000/. `localhost` считается защищённым контекстом,
поэтому `AudioWorklet` работает. Для обычного домена нужен HTTPS.

Звук появляется после нажатия **«Пуск»** — браузер не даёт создать
`AudioContext` до действия пользователя.

## Как устроено

Каждый генератор — это отдельный `AudioWorkletProcessor`. Узлы создаются
лениво, при первом нажатии «Пуск», чтобы не нарушать политику
автовоспроизведения. Параметры летят в процессор через `port.postMessage` и
сглаживаются внутри аудиопотока, поэтому резкие движения ползунков не дают
щелчков.

Все голоса суммируются в общую шину, проходят через мастер-гейн и мягкий
лимитер, а затем через `AnalyserNode` уходят в выход. Анализатор используется
сразу двумя визуализациями: осциллографом (`fftSize` 8192) и спектром
(96 логарифмических полос).

Патч — это обычный JSON. Он сохраняется в `localStorage` и кодируется в
base64url для ссылки `#p=...`; при загрузке страницы ссылка имеет приоритет
над локальной копией.

## Браузеры

Chrome, Edge, Firefox и Safari 16.4+. Нужен `AudioWorklet` и защищённый
контекст (HTTPS или `localhost`).
